CodebookSend a message

Pay by the token.

Telegraph companies charged by the word, so businesses bought code books that swapped common phrases for single code words. A GPT tokenizer does the same with bytes: it learns which strings come up most and gives each one a number, and a language model reads, and bills, by the number. This one is written from scratch in Rust and runs in this page. It learned its book from IMDB reviews in half a second, and, loaded with GPT-4's book, it matches tiktoken token for token.

    A book fits its text

    Nothing is unknown

    The book starts with all 256 bytes, so any text can be encoded, including emoji and scripts it never saw. They just cost more: a Chinese character it has no entry for takes three code words, one per byte. Try "three languages" on the first spread.
